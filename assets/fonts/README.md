Place the licensed Telegraf webfont files in this folder with these names:

- `Telegraf-Regular.woff2`
- `Telegraf-Regular.woff`
- `Telegraf-Regular.otf`
- `Telegraf-Bold.woff2`
- `Telegraf-Bold.woff`
- `Telegraf-Bold.otf`

The site already has `@font-face` rules in `assets/wiki.css` that load these
files when present. Do not commit unlicensed commercial font files.
