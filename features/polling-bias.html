More about the calculation

The map is FEA’s adjusted estimate for 2026. The historical average below describes past polling errors before that adjustment. These are different measures, so only the 2026 estimate appears on the map.

Historical average miss
Regional starting point
Combined evidence weight
Consistency adjustment

Regional starting points help when a state has few polls. Evidence weight is a calculation score, not a poll count or a probability. The consistency adjustment is an input to FEA’s calculation. Evidence confidence is a qualitative label, not the chance that a party will win.

How historical races contribute

Most races use polls from the last 21 days before the election. Some use up to 45 days when recent polling is sparse. Extreme misses are limited to 12 points in either direction for the calculation; the main table still shows the actual miss. Weight shares are approximate percentages and may not add to 100 after rounding.

A little context

This is about polling accuracy

A state can lean strongly Republican and still have a Democratic polling bias, or the other way around. The color shows which party polls may overstate, not which party is expected to win the state.

Some states have much less evidence

The estimates use Senate polling and election results from 2014 through 2024. A large estimated miss can come from a small sample. Oklahoma has no usable Democratic-versus-Republican Senate race in this dataset, so its estimate relies on its region and has very low confidence.
